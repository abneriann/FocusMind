# Identidade visual do FocusMind

**Evolua do seu jeito.**

Esta pasta contém imagens do kit corrigido `FocusMind_Identidade_Oficial_v3_CORRIGIDA.zip`, preservadas **sem redesenhar, substituir ou recolorir a arte aprovada**.

## Organização

| Diretório | Conteúdo |
|---|---|
| `reference/` | Painel visual original aprovado para comparação |
| `logo/` | Logo principal com rosto integrado ao F, logo completa com slogan e recortes do símbolo |
| `symbol/` | Letra F simplificada: gradiente original, versões monocromáticas e recortes |
| `wordmark/` | Nome FocusMind e nome acompanhado do slogan |
| `app/` | Ícones de aplicativo em múltiplas resoluções e ícone Windows (`.ico`) |
| `variations/` | Aplicações visuais para fundo claro, escuro e laranja |

## Regras de marca

- Nome: **FocusMind**
- Slogan: **Evolua do seu jeito.**
- Laranja principal de referência: `#FF702B`
- Apoio: `#FFF7ED` e `#30231D`
- A marca principal integra o rosto humano, a letra F e um brilho.
- A versão simplificada usa apenas o F original.
- Não trocar o logo por arte gerada, nem usar os ícones de módulos como se fossem a marca.
- Arquivos PNG são rasterizados; versões vetoriais aproximadas não foram incluídas como “oficiais”.
